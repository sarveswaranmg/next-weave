## ⚡ Quick Command Reference

### Deploy
```bash
alembic upgrade head          # Run migration
pytest tests/ -v               # Run tests
docker-compose restart         # Restart service
```

### API
```bash
# Score memory
curl -X POST http://localhost:8000/cognitive/score \
  -H "Content-Type: application/json" \
  -d '{"user_id":"<uuid>","memory_id":"<uuid>","use_llm":true}'

# Get stats
curl http://localhost:8000/cognitive/stats?user_id=<uuid>

# Reinforce
curl -X POST http://localhost:8000/cognitive/reinforce \
  -H "Content-Type: application/json" \
  -d '{"user_id":"<uuid>","memory_id":"<uuid>"}'
```

### Monitoring
```bash
# Check memory distribution
curl http://localhost:8000/cognitive/stats?user_id=<uuid> | jq '.memory_state_distribution'

# Monitor retrieval performance
curl http://localhost:8000/cognitive/stats?user_id=<uuid> | jq '.importance_distribution'
```

## 🎯 Key Takeaways

### What This Is
NeuroWeave Day 2 adds **intelligent memory management** to the system. It understands which memories matter and why, automatically manages their lifecycle, and retrieves what's important first.

### How It Works
1. **Score**: Analyze memory across 5 cognitive dimensions
2. **Store**: Assign lifecycle state and metadata
3. **Reinforce**: Strengthen related memories on repetition
4. **Decay**: Automatically fade forgotten memories
5. **Retrieve**: Return high-value memories first

### Why It Matters
- Better retrieval (high-value first)
- Natural forgetting (no manual deletion)
- Smart reinforcement (concepts strengthen together)
- Automatic lifecycle (no manual state management)
- Identity preservation (important memories persist)
